# Veda Stack Consulting – Training Materials

Central hub for all Veda training programs and materials.

## Structure

- **2-hour-introductory/** - Quick-start sessions for non-technical professionals
- **2-day-intensive/** - Compressed workshops for teams and institutions
- **15-day-comprehensive/** - Full-semester courses with projects and capstone
- **shared-resources/** - Common assets (videos, datasets, code snippets)

## Getting Started

1. Choose your course level
2. Navigate to the relevant folder
3. Start with README.md in that folder
4. Follow the curriculum structure
